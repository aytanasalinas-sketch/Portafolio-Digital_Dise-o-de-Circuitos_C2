1. Sumar un bit

Hay solo 4 casos. S = suma (lo que escribo) y C = carry/acarreo (lo que «me llevo»). Igual que 7 + 5 = 12 → escribo 2, llevo 1.

0110 + 0111 = 1101 (6 + 7 = 13). El acarreo de una columna entra a la siguiente: se encadenan.

S = 1 cuando hay un número impar de unos.
S = A ⊕ B ⊕ Cin (en el K-map es un «tablero de ajedrez»: no hay grupos).

Cout = AB + A·Cin + B·Cin (tres grupos de dos).

4. Sumador de 4 bits (ripple carry)

Regla única: Cout de un sumador → Cin del siguiente. El acarreo avanza como una ola, por eso el resultado se completa de derecha a izquierda.

Retardo ≈ 2 · n · 10 ns (cada compuerta ≈ 10 ns, el acarreo cruza ≈ 2 por etapa)

5. Restar con el mismo circuito

A − B = A + (−B) donde −B = invertir bits de B y sumar 1. Ejemplo: 6 − 3 → 0110 + 1101 = 1 0011 → 0011 = 3 ✓ (el 1 sobrante se descarta).


Una XOR es un inversor controlado: B ⊕ M.
M = 0 → B pasa igual → SUMA
M = 1 → B se invierte → RESTA
Además M se conecta al Cin del sumador 0 (aporta el +1).

6. Overflow

0101 (+5) + 0100 (+4) = 1001 → −7 ✗ (con 4 bits el rango es −8 a +7).
V = C3 ⊕ C4 hay overflow si el acarreo que entra a la última etapa ≠ el que sale. Cout = 1 NO significa error.

7. Comparador de magnitud

¿A = B? XNOR en cada bit y AND de todas.
¿A > B? Desde el bit más alto: el primer bit en que difieren decide. Integrado 7485.

8. De aquí sale la ALU
