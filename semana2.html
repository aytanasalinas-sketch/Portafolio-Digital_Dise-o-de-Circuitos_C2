1. Circuito = expresión


Cable = variable · AND = producto (·) · OR = suma (+) · NOT = complemento (').
Y = A·B + C' Precedencia: NOT → AND → OR.

2. Álgebra de Boole

Conjunto {0,1} con tres operaciones: + (OR), · (AND), ' (NOT). Principio de dualidad: al intercambiar + ↔ · y 0 ↔ 1 la identidad sigue siendo válida.

PostuladoForma ORForma AND (dual)
IdentidadX + 0 = XX · 1 = X
ComplementoX + X' = 1X · X' = 0
ConmutativaX + Y = Y + XXY = YX
DistributivaX(Y+Z) = XY + XZX + YZ = (X+Y)(X+Z)

Teoremas útiles

TeoremaForma ORForma AND
Elemento nuloX + 1 = 1X · 0 = 0
IdempotenciaX + X = XX · X = X
AbsorciónX + XY = XX(X+Y) = X
Abs. del complementoX + X'Y = X + YX(X'+Y) = XY
AdyacenciaXY + XY' = X(X+Y)(X+Y') = X
ConsensoXY + X'Z + YZ = XY + X'Z(X+Y)(X'+Z)(Y+Z) = (X+Y)(X'+Z)

3. Leyes de De Morgan


(AB)' = A' + B'

(A+B)' = A'·B'
Regla: rompe la barra y cambia el operador. Generaliza: (A+B+C)' = A'B'C'.

5. Formas canónicas SOP y POS

Caso de la alarma de 3 sensores (puerta A, ventana B, movimiento C): la sirena F suena si al menos dos sensores se activan.

SOP · mira los 1
F = Σm(3,5,6,7) = A'BC + AB'C + ABC' + ABC
POS · mira los 0
F = ΠM(0,1,2,4) = (A+B+C)(A+B+C')(A+B'+C)(A'+B+C)

Los índices de ΠM son los que faltan en Σm. Se elige SOP si hay pocos 1 (o solo NAND) y POS si hay pocos 0 (o solo NOR).

6. Simplificar: ¡ahorra hardware!

Con idempotencia (ABC se usa tres veces) y adyacencia: A'BC+ABC = BC, AB'C+ABC = AC, ABC'+ABC = AB.
